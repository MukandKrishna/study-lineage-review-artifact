# Lineage-overlap control

This exploratory control uses one source-reviewed ProMISe/ARISE family. It crosses same-trial and independent-trial evidence with high- and low-overlap passages.

The control uses an explicit lineage policy and is separate from the confirmatory 14-family denominator. It tests policy application, not unprompted lineage discovery or a causal effect of textual overlap.

The four frozen inputs, bundle manifest, prompt, schema, model outputs, and audit report are included here or in the linked experiment records. GPT-5.5 has five repetitions per cell; each open model has one recorded call per cell. Repetitions indicate within-input stability, not independent clinical cases.

The historical bundle uses `replacement_same_high`, `replacement_same_low`, `replacement_independent_high`, and `replacement_independent_low` as condition IDs. These names refer to the final ProMISe/ARISE cells; they are not additional experiments.

`overlap_construction.csv` records the frozen passage lengths and overlap scores used to define the four cells.
